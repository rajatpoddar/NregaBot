# Brag Plan: NREGA Bot (Vertical Marketing Reel)

## What is this app?
NREGA Bot is a desktop automation suite that automates data entry on the Indian MGNREGA / VB-G-RAM-G portal for Gram Rozgar Sevaks, Panchayats, and BDO offices.

## The angle
Fast-paced, mobile-first vertical marketing reel: "Hours of manual portal work condensed into 1-click background automation."

## Hook (first 2-3 seconds)
Giant vertical display text: "STILL TYPING NREGA DATA MANUALLY?" → Red cross animation → Slam in blue accent text: "Automate 48+ Tasks in Seconds 🚜⚡"

## Key moments (the middle)
- **Metric Highlights**:
  - `⚡ 10x Faster Data Entry`
  - `📋 48+ Automated Tasks`
  - `🎯 0 Fat-Finger Typing Errors`
  - `📊 1-Click Excel & WhatsApp Reports`
- **Visual Reel Mockup**: Vertical app card showing Muster Roll Generator, Demand Automation, eMB Entry, and FTO Verification sliding up.

## Outro / punchline
"Join Thousands of Panchayats. Work Smarter, Not Harder." → NREGA Bot v3.2.9 Logo & Download CTA.

## User flow worth showing
Select Panchayat → Hit ▶ Start Automation → Browser runs in background → Instant WhatsApp Excel report notification.

## Tone

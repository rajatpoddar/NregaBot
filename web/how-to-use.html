How to Use the App

Follow these simple instructions for each automation feature.

1. Demand Automation

  1. Prepare a CSV file containing two columns: `Name of Applicant` and `Job card number`.
  2. In the app, select the 'State', 'Panchayat', 'Demand/Work Date', and 'Days'.
  3. (Optional) 'Work Key (Auto-Allocate)' field mein ek work key search key (e.g., 94297) enter karein.
  4. Click "Load Applicants CSV" and select your prepared CSV file.
  5. Select the applicants you want to process.
  6. Click "Start Automation".
  7. Workflow: Agar aapne 'Work Key' enter kiya hai, toh demand poora hone ke baad bot automatically 'Work Allocation' tab par switch karega aur uss key ke liye allocation run karega.

2. Muster Roll (MR) Generator

  1. Enter your full Panchayat name (e.g., KASRAYDIH).
  2. Select the 'From' and 'To' dates using the calendar.
  3. Enter the exact Designation and Technical Staff names.
  4. Paste one or more Work Codes into the text box. To run for all available works, leave this box empty.
  5. Choose an output action (Save as PDF or Print).
  6. Click "Start Automation".
  7. New: After the run, go to the "Results" tab and click "Merge Saved PDFs" to combine all generated muster rolls into one file.

3. MSR Processor

  1. First, manually navigate to the MSR Payment page in the launched browser.
  2. Enter the Panchayat name exactly as it appears on the website.
  3. Paste the list of Work Codes to process.
  4. Click "Start Automation". The results will appear in the "Results" tab.

4. Duplicate MR Print

  1. Enter the Panchayat Name.
  2. Choose an output action (Save or Print).
  3. Paste a list of work code search keys (e.g., 94297) or full workcodes.
  4. Click "Start Automation". The app will find and process all MSRs for each work code.
  5. New: After the run, go to the "Results" tab and click "Merge Saved PDFs" to combine all saved muster rolls into one file.

5. Update Estimated Outcome

  1. Enter the desired "Estimated Outcome" value (e.g., 0.20).
  2. Paste a list of full work codes into the text box.
  3. Click "Start Automation".

6. FTO Generation

  1. First, log in to the 1st Signatory account in the launched browser.
  2. Return to the app and click "Start FTO Generation".
  3. The app will automatically visit the 'Aadhaar FTO' and 'Top-Up FTO' verification pages and process all entries.
  4. Workflow: After completion, a "Check Pending ABPS Labour" button will appear. Click it to go to the MR Tracking tab and find pending ABPS laborers.

7. Wagelist Generator

  1. Manually navigate to the "Send MSR to PO" page in the browser.
  2. Enter the Agency name (e.g., BURKUNDI) without "Gram Panchayat -".
  3. (Optional) Check "Save generated wagelist page as PDF" to save a PDF copy of each wagelist as it's generated.
  4. (Optional) Check "Send generated wagelist range..." to automatically send the first and last generated wagelist numbers to the 'Send Wagelist' tab.
  5. Click "Start Generation" to process all available items one by one.

8. Send Wagelist

  1. Select the Financial Year in the app.
  2. Enter the Start and End Row numbers for the checkboxes you want to select on the page.
  3. Click "Start Sending". The app will automatically navigate and process each wagelist.

9. Jobcard Verification & Photo

  1. Enter the Panchayat and Village name.
  2. Click "Select Photo Folder" and choose a folder containing photos named after the job card suffix (e.g., `417.jpg` for `.../417`).
  3. If a photo isn't found, the default `jobcard.jpeg` will be used.
  4. Click "Start Verification" to process all job cards for the village.

10. eMB Entry

  1. Fill in all the configuration details like Panchayat, MB No., Page No., etc.
  2. Paste the list of Work Codes to process.
  3. Click "Start Automation" to fill and save the MB Entry form for each work code.

11. eMB Verify

  1. Enter the Panchayat name.
  2. Paste a list of full Work Codes into the text box.
  3. Click "Start Automation". The bot will verify the eMB for each work code provided.

12. Scheme Closing

  1. Enter the Panchayat name.
  2. Paste a list of full Work Codes of the schemes you want to close.
  3. Click "Start Automation". The bot will process and close each scheme.

13. Delete Work Allocation

  1. Enter the Panchayat name.
  2. Paste a list of Muster Roll Numbers (not work codes) to process.
  3. Click "Start Automation". The bot will delete the work allocation for each MSR number.

14. Verify ABPS

  1. Enter the Panchayat name.
  2. Optionally, enter a Village name. If you leave this blank, the app will process all villages in that Panchayat.
  3. Click "Start Automation". The bot will check every record, page by page, and save the results.

15. Add Activity

  1. Enter the desired Unit Price and Quantity.
  2. Paste the list of Work Keys (not full work codes) to process.
  3. Click "Start Automation" to add the default activity (ACT105) to each work key.

16. Workcode Extractor

  1. This is a simple utility tool.
  2. Paste any block of text that contains NREGA work codes into the text area.
  3. Click the "Extract Work Codes" button.
  4. A clean, unique list of work codes will be generated and automatically copied to your clipboard.

17. Workcode Generator (Dynamic)

Instructions

  1. Enter the Panchayat name and click "Load Categories from Website".
  2. Make your selections for all dropdowns from top to bottom.
  3. Prepare a CSV file with the 9 required columns (see demo).
  4. Select your CSV file.
  5. Click "Start Automation" to generate work codes based on your selections and CSV data.

Demo CSV Format

priority,work_name,...,total_saplings
Download Demo CSV

18. IF Editor (Dynamic)

Instructions

  1. Prepare a CSV file with 7 columns (see demo). One row for each Activity/Material to add.
  2. In the app, configure the settings for Page 1 and Page 2.
  3. Use the switch to enable/disable the multi-page (convergence) workflow.
  4. Select your CSV file.
  5. Click "Start Automation".

Demo CSV Format

work_code,beneficiary_type,...,quantity
Download Demo CSV

19. Cloud Storage Manager

  1. Access your personal cloud storage included with your license.
  2. Upload, download, and manage your important files directly within the app.
  3. Create folders to keep your documents organized.
  4. Generate secure, shareable links for your folders to collaborate with others.
  5. Your files are accessible from any device where you log in to NREGA Bot.

20. MR Fill (Attendance)

  1. Enter the Panchayat Name (this is required if you are using a Block login).
  2. Enter "Holiday Columns" (e.g., 7, 14) to have the bot automatically mark those days as holidays.
  3. Check "Manual Mode" to pause the bot after it marks holidays. This allows you to manually mark absentees before clicking 'Save' in the browser.
  4. Paste your list of Work Codes (search keys) into the text box.
  5. Click "Start Automation".
  6. Workflow: You can also send workcodes and the panchayat name here directly from the 'Dashboard Report' tab.

21. MR Tracking

  1. Select your State, District, Block, and Panchayat.
  2. Check one of the filters: "Pending for filling", "Pending for ABPS", or "Find T+8 to T+15 (for Zero MR)".
  3. Click "Start Automation".
  4. If "Pending for ABPS" is checked, the bot will find all pending wagelists and then scan each one to find the specific laborers causing the pendency.
  5. Results are shown in the "Results Table" and "ABPS Pendency Results" tabs.
  6. Workflow: Depending on your filter, a button will appear. "Run MR Payment" (sends to MSR Processor), "Run eMB Entry" (sends to eMB Entry), or "Forward to Zero MR" (sends to Zero MR tab).

22. Dashboard Report

  1. Select your State, District, Block, and Panchayat.
  2. Choose the "Delay Column" you want to investigate from the dropdown (e.g., "Attendance not filled in T+2 days").
  3. Click "Start Automation".
  4. The bot will navigate the MIS dashboard and pull the detailed report.
  5. Workflow: If you selected the "Attendance not filled..." delay column, a "Run MR Fill" button will appear. Click it to send the pending workcodes and panchayat name directly to the 'MR Fill' tab for processing.

23. Issued MR Details

  1. Select your State, District, Block, and Panchayat.
  2. Click "Start Automation".
  3. The bot will navigate to the 'MGNREGS daily status as per e-muster issued' report for your block.
  4. It will find your panchayat and click the link under "No. Of Ongoing Works on which MR Issued".
  5. The bot will scrape all work details from the final page and list them in the "Results Table".
  6. Workflow: Go to the "Workcode List" tab and click "Run Duplicate MR Print" to send all extracted workcodes and the panchayat name to the 'Duplicate MR Print' tab.

24. PDF Merger

  1. This is a standalone utility to combine multiple PDF files.
  2. Click "Select PDF Files..." and choose two or more PDFs.
  3. The files will appear in the list. You can use "Move Up", "Move Down", or "Remove" to set the correct merge order.
  4. Enter a base "Output File Name" (e.g., "Merged_MRs").
  5. Click "Merge Selected PDFs".
  6. The final, combined PDF will be saved in your "Downloads/NregaBot/Merged_Pdf_Output" folder.

25. Zero MR

  1. Select the correct "Financial Year".
  2. Enter the "Panchayat Name" exactly as it appears on the website.
  3. In the "Work List" tab, paste your items. Each line must be in the format: SearchKey,MSRNo (e.g., 58744,32158).
  4. Workflow: You can get this data automatically by using the "Find T+8 to T+15" filter in the "MR Tracking" tab and clicking "Forward to Zero MR".
  5. Click "Start Automation". The bot will process each item, select the correct work code and MSR, and save it as a Zero MR.

26. Work Allocation

  1. (Optional) Agar PO/Block login hai toh "Panchayat Name" enter karein. GP login ke liye yeh zaroori nahi hai.
  2. "Work Category" select karein (default 'Provision of Irrigation...' hai).
  3. "Work Key List" tab mein ek ya zyada Work Keys (search keys, e.g., 94297) paste karein.
  4. Click "Start Automation". Bot har work key ke liye 'Allocate All' karega aur 'Save' par click karega.
  5. Note: Yeh automation "Demand" tab se automatically bhi run ho sakta hai (upar dekhein).

27. Delete Demand

  1. NREGA portal par Data Entry login karein.
  2. Panchayat select karein.
  3. Agar aapko sirf ek gaon ka demand delete karna hai, toh Village Name select karein.
  4. Agar pure panchayat ka delete karna hai, toh village dropdown me "ALL VILLAGES" select rehne dein.
  5. "Start Automation" par click karein. Bot automatically check karega aur demand delete karta jayega.
  6. Note: Yeh process background me portal ke glitches ko bhi handle kar leta hai.

28. Mate/Mistri MR Generation

  1. Enter the Panchayat name.
  2. Select the 'From' and 'To' dates.
  3. Paste the list of Work Codes you want to process.
  4. Choose output action (Save as PDF or Print).
  5. Click "Start Automation" to generate Mate/Mistri formatted muster rolls.
  6. Note: This is specifically designed for Mate/Mistri MR formats and is fully compatible with the VB-G-RAM-G portal.

29. Physical Complete

  1. In the browser, navigate to the Physical Complete page for the scheme.
  2. Enter the Panchayat name in the app.
  3. Paste the list of Work Codes to process.
  4. Click "Start Automation".
  5. Workflow: After Physical Complete is done, the bot will auto-forward to the Scheme Closing tab for seamless processing.

30. Resend Rejected Wagelist

  1. In the browser, log in and navigate to the Rejected Wagelist page.
  2. Enter the Agency (Panchayat) name.
  3. Click "Fetch List" to load all rejected wagelists.
  4. Select the wagelists you want to resend.
  5. Click "Resend Selected" to process them for payment again.

31. Login Automation

  1. Go to the 'Login Automation' tab in the app.
  2. Enter your NREGA portal credentials (Username, Password, and PIN).
  3. Click "Save Credentials" to store them securely.
  4. Whenever you need to log in, simply click "Auto Login" and the bot will log you into the portal with a single click.

32. Macro Manager

  1. The ultimate automation hub to queue multiple tasks in sequence.
  2. Add tasks like 'Bulk Demand via CSV', 'Work Allocation', 'MR Fill', and more.
  3. Configure each task with its required parameters.
  4. Arrange the order of tasks as needed.
  5. Click "Run All" to execute the entire workflow automatically.
  6. Note: Supports Bulk Demand via CSV for processing large datasets.

33. Material Entry

  1. Enter Work Keys (search keys) in the input field.
  2. Enter Bill Numbers for each work.
  3. Fill in Material details like item description and quantity.
  4. Click "Start Automation" to auto-fill the portal's material bill entry page seamlessly.
  5. The bot will handle the entire entry process work by work.

34. Delete Applicant

  1. Prepare a CSV file containing job card numbers of applicants to delete.
  2. In the app, click "Load CSV" and select your prepared file.
  3. The bot will automatically detect the village from job card numbers and select the correct panchayat.
  4. Click "Start Automation" to delete the listed applicants from the portal.

35. MIS Reports

  1. Select the Report Type (e.g., Work Progress, Expenditure, etc.).
  2. Select State, District, Block, and Panchayat as needed.
  3. Choose the Financial Year and Time Period.
  4. Click "Start Automation" to fetch and generate the MIS report.
  5. Results are displayed in the app and can be exported for further analysis.

36. eKYC Report

  1. Select State, District, Block, and Panchayat.
  2. (Optional) Enter a specific Village name to filter results.
  3. Click "Start Automation" to fetch eKYC verification status for all job card holders.
  4. The bot will scrape the eKYC report page by page and display results.
  5. Export the data for offline record-keeping or further processing.

37. Social Audit Report

  1. Log in to the PO (Block) account in the browser.
  2. Navigate to D23 > Social Audit View page.
  3. Select the Financial Year and Panchayat.
  4. Click "Start Automation" in the app.
  5. The bot will fetch all Social Audit issues and their status.
  6. Use the interface to view issues and respond to them directly from the app.

38. NMMS Daily Attendance

  1. Enter the District, Block, and select the date for attendance.
  2. Click "Start Automation" to scrape NMMS daily attendance data.
  3. The bot will navigate the NMMS portal and fetch attendance for all schools.
  4. Results are organized by school with attendance status.
  5. Export the complete report for monitoring and record purposes.

39. Sarkar Aapke Dwar (AYASAD)

  1. Select the Camp/Event details and Scheme name.
  2. Prepare a CSV file with applicant details as per the camp format.
  3. Load the CSV file in the app.
  4. Click "Start Automation" to enter bulk data for the Sarkar Aapke Dwar camp.
  5. The bot will fill all application entries automatically in the portal.

40. SAD Update Status

  1. Select the Camp details and date.
  2. Paste or load the list of application reference numbers.
  3. Click "Start Automation".
  4. The bot will check the current status of each application submitted during Sarkar Aapke Dwar camps.
  5. It will automatically update the status records in the system.

41. File Manager

  1. Open the File Manager tab in the app.
  2. Browse your local files and folders directly within the app interface.
  3. Organize downloaded reports, PDFs, and CSV files into folders.
  4. Use the built-in preview to view files without leaving the app.
  5. Easily locate and manage all your NREGA-related documents in one place.
